# IELTS Fieldnotes

一个中文优先、无需安装依赖的雅思学习网页。打开 `index.html` 即可使用；学习进度保存在当前浏览器的 `localStorage` 中。

## 功能

- 今日任务清单、学习路线和进度记录
- 听力、阅读、写作、口语练习
- 原创短文精读、逐句翻译和单词查询
- 每日 30 张词汇卡：音标、中文释义、用法、语境、关联词和例句
- 本地词汇查询；未收录词可跳转 Cambridge Dictionary
- 目标分数、考试日期和学习进度保存在本地
- 桌面和手机自适应布局

题目、短文和例句为本项目原创。网页使用浏览器内置语音合成进行听力播放，不上传用户数据。
